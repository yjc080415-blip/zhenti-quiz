# 真题前30 听力刷题

30 套听力真题的手机刷题站：音频、选项、答案、原文、生词，进度保存在浏览器。

## 启动

电脑和手机连同一个 Wi-Fi，在本目录运行：

`ash
python server.py
`

用手机浏览器打开终端里的 Phone 地址，例如 http://192.168.x.x:8765/

可在手机浏览器选择「添加到主屏幕」。Windows 防火墙若弹出，请允许 Python 访问专用网络。

## 功能

- 对话回复逐题播放，选完立刻对答案
- 短对话 / 公告 / 讲座先听整段再提交
- 0.75x-1.5x 倍速、整卷刷、错题本、夜间模式
- 重新解析题库：python scripts/parse_papers.py

题库来自本地微信文件，仅供个人练习。
